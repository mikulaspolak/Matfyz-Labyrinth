# Matfyz-Labyrinth

A Unity coursework project featuring a 3D maze game with a rabbit player.

## Gameplay

At startup, the game generates a randomized maze and places the rabbit at a starting position. The maze is checked for a route to the goal. A timer tracks the run; reaching the goal displays the elapsed time and restarts the scene.

The `GameStart` component exposes `MoveRabbit(direction)` for movement. Verify the input or Unity event wiring in the scene before documenting specific keyboard or controller controls.

## Open the project

The project was created with Unity 2019.3.0f5. Open this folder in that Unity version and open the game scene:

```text
Assets/Scenes/SampleScene.unity
```

Newer Unity versions may require project migration. The existing APK is a build artifact, not required to open the Unity project.
